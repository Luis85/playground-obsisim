# Project skills

The skill directories here are vendored from [obra/superpowers](https://github.com/obra/superpowers)
(v6.1.1, commit `d884ae04edebef577e82ff7c4e143debd0bbec99`), MIT licensed — see `LICENSE-superpowers`.

Claude Code auto-discovers each `<skill-name>/SKILL.md` in this directory, so these skills are
available to anyone working in this repository. The `using-superpowers` skill is the entry point
that explains how the rest fit together.

To update, re-copy the `skills/` directory from the upstream repo and bump the commit hash above.
