# Arm, Preview and Place a Building

The World tab's palette arms a building for placement; a ghost preview follows the cursor, colored accent when the tile is buildable and red when blocked, and clicking places it. Placement stays armed afterward so repeat building doesn't mean re-opening the palette each time.
