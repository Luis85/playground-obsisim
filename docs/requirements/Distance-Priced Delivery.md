# Distance-Priced Delivery

Distance is now a real cost rather than cosmetic: a building beside the camp is a one-tick walk for a hauler, the far corner of the 24x16 map is thirteen — so where a player builds changes what they actually get out of it. Increment 5's balance harness later measured the gradient this created and corrected the increment's own initial estimate of how many haulers a distant building needs.
