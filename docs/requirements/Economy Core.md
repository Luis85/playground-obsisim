# Increment 1 - Economy Core

The first playable slice: a 2-tick/second deterministic sim-ecs world, two production chains (berries & wheat→flour→bread, wood→planks→tools), workers whose hunger drives efficiency, a tools loop that rewards keeping workers equipped, and a table-only UI backed by a single-slot autosave. No graphics yet — the table UI was built as a first-class interface, not a placeholder for one.
