# Haulers as a Staffed Role

Haulers are assigned on the Dashboard like any other worker. Each walks to the fullest building, loads up, and carries goods back to the camp store — the camp itself being the store the whole colony draws from and delivers to. The haul rule that picks which building a hauler serves next exists in exactly one place.
