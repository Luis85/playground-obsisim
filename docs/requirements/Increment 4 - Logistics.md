# Increment 4 - Logistics

A building banks what it makes in its own output buffer and stalls ("Output full") when that buffer fills. Haulers — a staffed role assigned on the Dashboard — walk to the fullest building, load up, and carry goods back to the camp store; distance is now a real cost. The Economy view names the backlog (units waiting, buildings stalled, haulers on duty) so a production drop is never a mystery. Save v3 persists buffers and hauler assignments; v2 colonies load as themselves, with empty buffers and nobody hauling yet.
