# One Ledger, Held in Several Places

A storehouse does not own a separate economy; it holds part of the same one, at a different tile. Meals, construction costs, demolition refunds and colony wealth all count depot stock exactly as they count camp stock, and an aggregate spend drains the unbounded camp before the bounded depots so a local store stays stocked for the haulers that need it. Goods still do not change *what they are* — only *where they must be fetched from*.

The accounting that goes with it is the part a player notices when it is wrong: goods loaded for a delivery are in transit rather than gone, goods entering a building's in-tray are consumed, collected output arriving at a site is a delivery, and an undelivered supply load carried back home is none of those — the colony already owned it, and counting it would report banked inputs as newly delivered output.
