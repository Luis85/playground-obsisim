# Population View - a New Primary Screen

A new `/population` route becomes the increment's primary screen for the colony's demographics: stage counts, beds used, meals/head against the birth threshold, and a colonist table with age, stage, home, commute, hunger and the starvation clock. The app's default route (`/`) stays the Dashboard — Population sits alongside it as its own top-level view, not a replacement for it. The world view gains a house glyph, stage markers and a homeless flag, each with its own legend entry.
