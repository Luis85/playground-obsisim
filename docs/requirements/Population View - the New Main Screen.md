# Population View - the New Main Screen

The Population view replaces the Dashboard as the game's default screen: stage counts, beds used, meals/head against the birth threshold, and a colonist table with age, stage, home, commute, hunger and the starvation clock. The world view gains a house glyph, stage markers and a homeless flag, each with its own legend entry.
