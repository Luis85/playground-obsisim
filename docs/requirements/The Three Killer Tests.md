# The Three Killer Tests

Increment 1's review found tests that passed with their feature entirely removed — a claim, not evidence. This item writes the three tests the review flagged so each one is proven to fail when its feature is deleted, then restored. It is the seed of the mutation-testing discipline `docs/process/agent-workflow.md` later made a standing rule for every increment after this one.
