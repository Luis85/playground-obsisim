# Tools Loop - the Tooled Worker Bonus

Tool coverage belongs to the worker, not the building: each staffed worker consumes 1 tool per 300 ticks when tools are available and works at +50% efficiency while covered. Coverage follows a worker across reassignment and wears down whether assigned or idle; a replacement worker pays for their own tool. Tools are never mandatory, only profitable — closing the loop so industry output feeds back into everyone's productivity.
