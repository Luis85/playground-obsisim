# World and Spatial Play

The colony stops being only a set of tables and becomes a place: a live 2D tile world the player can look at, then build on. Increment 2 made the world visible (Excalibur rendering, read-only); Increment 3 made it interactive (arm a building, place it, select it, move it, demolish it) and made position sim truth rather than decoration — a fixed 24x16 map that every later epic (Logistics' haul distance, Population's commute) prices against.

The table UI never regresses across this epic: every increment keeps full economic parity for players without WebGL.
